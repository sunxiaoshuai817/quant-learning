# 量化研究学习记录

这里整理了我学习量化过程中做的几个项目，包括券商金工研报复现和机器学习选股实验。代码以 Jupyter Notebook 为主，使用 Python 和聚宽数据。

## 项目

| 项目 | 内容 |
| --- | --- |
| [机器学习收益预测与组合评价](./ML_Alpha_Research/) | 比较 OLS、Ridge、LightGBM、LSTM 和 Transformer，观察 2024、2025 年的预测表现，以及换手和交易成本对组合收益的影响。 |
| [多因子指数增强](./multi-factor-enhancement/华泰多因子指数增强-2018.ipynb) | 复现多因子选股与沪深300指数增强，包含因子处理、分层抽样和约束优化。 |
| [聪明钱因子](./smart-money-factor/因子计算以及回测.ipynb) | 使用30分钟行情构造 Q 因子，进行参数比较、Rank IC 和分组收益检验。 |
| [RSRS 择时](./rsrs-timing/RSRS_2017.ipynb) | 复现 RSRS 及其修正指标，与常见择时方法进行回测比较。 |

## 运行说明

数据获取需要聚宽或 Tushare 的相应权限，仓库不包含完整原始行情。机器学习项目的运行顺序和结果见其 README，其他项目见对应 Notebook。

这些项目用于学习和研究，回测采用的假设与限制见各项目说明，结果不代表实盘表现。

研报复现参考了光大证券 RSRS、开源证券聪明钱因子及华泰证券多因子指数增强系列研究。
